# Как продолжить работу (протокол)

## Какой Claude нужен

Нужен **Claude Code на вашем компьютере с Windows**: в приложении Claude для компьютера
(режим Code) или в терминале. Только он может сам запустить программу на Windows,
посмотреть ошибки и исправить их.

Консоль platform.claude.com для этого не подходит: там ключи API и песочница для
запросов, программы она не запускает. Claude Code на сайте (claude.ai/code) может менять
код в этом репозитории, но Windows у него нет, поэтому проверить программу он не сможет.

## Шаги

1. **Скачайте проект** с GitHub:
   https://github.com/solzeworot-commits/article-downloader → зелёная кнопка **Code** →
   **Download ZIP**. Распакуйте в короткий путь, например `C:\Work\article-downloader`.
   (Или, если в Claude Code уже подключён GitHub, попросите его: «склонируй
   solzeworot-commits/article-downloader в C:\Work».)
   Если у вас сохранён `ArticleDownloader_Portable.zip` (готовая сборка), положите его
   рядом: так проверка пойдёт быстрее. Если его нет, Claude соберёт его сам.

2. **Установите Claude Code**, если его ещё нет. Проще всего через приложение Claude
   для компьютера. Или в PowerShell:
   ```
   irm https://claude.ai/install.ps1 | iex
   ```
   (Актуальная инструкция — на code.claude.com.)

3. **Подготовьте компьютер:**
   - лучше работать на компьютере в сети университета;
   - на рабочем компьютере **закройте старый загрузчик v5** (значок в трее → Выход):
     старый и новый используют один и тот же браузер и порт;
   - Яндекс.Браузер должен быть установлен (browser.yandex.ru, без прав администратора).

4. **Откройте папку в Claude Code.** В приложении выберите папку
   `C:\Work\article-downloader`. В терминале:
   ```
   cd C:\Work\article-downloader
   claude
   ```

5. **Вставьте первым сообщением** текст из раздела ниже.

6. **Ваша роль в сессии.** Claude будет просить:
   - запустить программу двойным щелчком и сказать, что вы видите;
   - **самому пройти капчу** и **войти через организацию** в окне браузера (за вас
     этого никто не сделает);
   - дать 5–10 DOI для проверки (подойдут из старых списков).
   Если что-то не так, присылайте снимок экрана или текст ошибки.

7. **В конце** попросите Claude пересобрать архив
   (`python tools\build_portable.py`) и показать, где лежит новый
   `ArticleDownloader_Portable.zip`. Этот zip и переносите на другие компьютеры.

## Первое сообщение для Claude (скопируйте целиком)

```
Продолжи работу над портативным загрузчиком статей (репозиторий
solzeworot-commits/article-downloader). Сначала прочитай HANDOFF.md в этой папке: там
задача, что уже сделано и проверено и что осталось.
Мы на Windows, на этом компьютере. Цель сессии:
1) собрать портативную версию через tools\build_portable.py (или взять готовый
   ArticleDownloader_Portable.zip, если он лежит рядом);
2) прогнать тестовый стенд из tests\ с отдельным тестовым профилем браузера, чтобы
   проверить всё, что в HANDOFF.md отмечено как «не проверено на Windows»;
3) вместе со мной проверить на настоящих базах: запуск двойным щелчком, открытие баз в
   Яндекс.Браузере, обнаружение капчи ScienceDirect, вход через организацию,
   скачивание 5–10 DOI;
4) исправить найденное в portable\ и пересобрать архив.
Капчи и вход через организацию прохожу я сам — говори, когда нужно. Не обходи капчи и
не убирай паузы между статьями. Объясняй по-простому, я не программист.
```

## Что в репозитории

| Что | Зачем |
|---|---|
| `HANDOFF.md` | Полное описание для Claude: задача, устройство, что проверено и что нет. |
| `CLAUDE.md` | Claude Code читает этот файл сам при открытии папки. |
| `portable\` | Исходники новой версии (без Python: его добавляет сборка). |
| `tools\build_portable.py` | Собирает готовую папку и zip. |
| `tests\` | Тестовый стенд: поддельный сайт с капчей, проверки. |
| `screenshots\` | Как выглядит окно программы. |
| `original_v5.24\` | Ваши старые скрипты для сравнения (без ваших PDF и логов). |
| `changes_article_downloader.diff` | Что именно изменено в загрузчике. |
