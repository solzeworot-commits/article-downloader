# Личные уведомления загрузчика

В личном чате с ботом проекта отправьте `/start`. Скопируйте ссылку из ответа целиком и вставьте в раздел **Настройки → Личные уведомления о капче**. Ссылка действует десять минут и подходит для подключения одного компьютера. Для второго компьютера запросите ещё одну ссылку. Кнопка «Проверить уведомление» отправит сообщение в тот же диалог.

После привязки загрузчик сообщает о ручной проверке во время скачивания. В сообщении нет DOI и названия статьи. Кнопка «Отвязать этот компьютер» отключает одну установку. Команда `/stop` в личном диалоге отключает все установки для этого диалога.

## Развёртывание для владельца проекта

Всем установкам достаточно одной службы на Cloudflare Workers Free и одной базы D1 Free. Доступы к ботам хранятся в секретах Worker. В базе хранятся идентификатор получателя, мессенджер, хеши одноразовых кодов и ключей компьютеров и время отправки.

Из каталога `notifications` с установленными Node.js и Python выполните:

```sh
npx wrangler@4 login
npx wrangler@4 deploy
npx wrangler@4 d1 execute article-downloader-notifications --remote --file schema.sql
```

При первом развёртывании Wrangler создаст привязанную базу D1 и выведет адрес Worker. Для каждого зарегистрированного бота выполните соответствующую команду, подставив этот адрес:

```sh
python register_bot.py telegram https://article-downloader-notify.YOUR-NAMESPACE.workers.dev
python register_bot.py max https://article-downloader-notify.YOUR-NAMESPACE.workers.dev
```

Скрипт запрашивает токен со скрытым вводом, записывает секреты в Worker и регистрирует вебхук. Для Telegram токен выдаёт [BotFather](https://t.me/BotFather). Для MAX бота регистрирует владелец верифицированного профиля на [платформе MAX](https://dev.max.ru/help/chatbots).

Перед публикацией пользовательской сборки укажите в настройках ссылки на подключённых ботов и проверьте доставку через кнопку «Проверить уведомление».
