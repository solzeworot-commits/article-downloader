2. Базы

Нажмите на базу. В окне браузера загрузчика откроется вход через организацию: выберите свой университет и войдите. Делается один раз на компьютере (иногда сайты просят войти снова через несколько недель).

3. Очередь

1. Ключевые словакаждое слово или фраза — с новой строки; лучше по-английски

Подберёт частые ключевые слова из статей по вашей теме (бесплатно, OpenAlex).

2. Где и как искать

Запрос для Scopus
Запрос для Web of Science
Запросы собираются сами из ключевых слов, их можно поправить.
  1. Нажмите кнопку: сайт откроется в браузере загрузчика (там вы вошли через университет), а запрос скопируется сам.
  2. Если поле поиска на сайте пустое — щёлкните в него, нажмите Ctrl+V и «Search».
  3. Нажмите на сайте «Export» («Экспорт»). В Scopus выберите формат CSV или RIS, в Web of Science — «Plain text file» или «Tab delimited file».
  4. Программа сама найдёт скачанный файл в папке «Загрузки»:

🔑 Ключи APIвводятся один раз и хранятся только на этом компьютере

Ключ — это длинный «пароль» из букв и цифр, по которому Scopus и Web of Science пускают программу. Выберите базу и пройдите шаги по порядку: кнопки «👉 Открыть страницу» сами откроют нужный сайт. Никому не показывайте ключ. Без ключей можно искать «Через браузер».

Если подписки на Scopus нет, ключ Scopus почти ничего не даст: ищите в Web of Science (есть бесплатный план) или OpenAlex (без ключа).
